# Release & Signing (current state, stated as-is)

## Installer

```bash
npm run dist   # electron-builder → release/Lynn-<version>-setup.exe (NSIS, x64)
```

- asar is disabled (the RPC subprocess needs real file paths to load Pi ESM packages — trading size for stability).
- App data lives in `~/.lynn`, separate from the install dir; upgrades and uninstalls keep it.

## Signing (not yet — stated as-is)

- The installer is **currently unsigned** — Windows SmartScreen may warn about an unknown publisher. This is a missing certificate (OV/EV) in the release process, not a technical blocker; this section will be updated when it lands.
- The updater (electron-updater) uses a generic feed: auto-download is off by default; configure via `LYNN_UPDATE_FEED` or `~/.lynn/updater.json`. Until signing lands, verify installer provenance yourself.
