# 快速开始（30 分钟跑通主流程）

目标：从零到「风铃派单给成员完成一件小事并向你汇报」。

## 1. 安装与启动（约 5 分钟）

- 前置：Windows 10/11 x64、Node.js ≥ 22、Git（可选）。
- Edge 浏览器建议已安装（浏览器执行域驱动你本机 Edge，不下载浏览器）。

```bash
git clone <本仓库> && cd lynn
npm install
npm run build    # typecheck + 渲染层 + 主进程
npm start        # electron .
```

开发模式（热重载）：`npm run dev`。

## 2. 配置模型（约 5 分钟）

首次启动会弹出「造铃向导」：选主题 → 选形象 → **填模型**（OpenAI 兼容端点 + API Key + 模型名，内置 DeepSeek / GLM / Kimi / Qwen / MiniMax 预设）→ 开始首聊。

- API Key 用系统 safeStorage 加密存放在本机 `%USERPROFILE%\.lynn\settings.json`，明文不落盘、不下发界面。
- 换模型 / 换厂商：设置 →「模型」，改 `models.yaml` 即可新增厂商，不用改代码。
- 数据根默认 `~/.lynn`，可用环境变量 `LYNN_HOME` 重定向。

## 3. 首聊与派单（约 10 分钟）

在指令台用一句话布置任务，例如：

> 把当前目录的 package.json 里所有依赖名列个清单，整理成 CSV，放到桌面工作区。

风铃（指挥者）会：建团队 → 招募成员 → 呈「任务契约卡」给你 → **你点「开始」才开工**（设置里可开自动开始）→ 成员在隔离工作区执行 → 交证据 → 风铃审查 → 向你汇报。

- 她本人**没有**读写文件 / 执行命令类工具——执行只发生在成员侧，工具白名单只能收窄。
- 打回要点名「哪里不合格 / 期望是什么 / 多久内重交」，满 3 轮她会升级问你。
- 工单、任务卷宗、证据链都在 `~/.lynn/tasks/<任务id>/`，可随时翻。

## 4. 完整能力速览（约 10 分钟）

| 能力 | 入口 / 说明 |
|---|---|
| 本地日历 / 提醒 / cron 定时任务 | 对话里说「两小时后提醒我…」「每天 9 点…」 |
| 知识库 | 对话里说「记住…」，检索用中文子串（≥3 字符） |
| 浏览器 | 成员工具：导航 / 快照 / 点击 / 填表 / 抓取落 CSV / 入知识库；登录 / 支付 / 验证码页强制要你确认 |
| 消息平台 | 只走官方 API（飞书开放平台 / QQ 机器人开放平台）+ 你自建的应用凭据；收消息未实现 |
| 插件 | 主题 / 语言包 / 技能（L0 声明式）、进程内扩展（L1）、MCP（L2）、界面组件（U）——见[插件开发指南](./plugin-guide.md) |
| 多会话 / 撤销 | 顶栏「新对话」「撤销改动」 |
| 语言 | 设置 → 外观 → 界面语言（中文 / English） |

## 常见问题

- **她没有回话？** 看指令台状态与顶部通知卡；`~/.lynn/logs/` 有 server / agent / tools 日志。
- **装了个插件界面崩了？** 10 分钟内 3 次启动崩溃会自动进安全模式（只跑官方核心）；顶栏可一键回滚到上一个插件集快照。
- **权限四档怎么选？** 计划（只读）/ 询问（逐次问）/ 自动（默认）/ 全权——「放手模式」在下轮起生效，硬性危险命令任何档都拦。
