# 隐私说明

版本：2026-11-03（与实现同步更新；口径纪律：**与实现一致，不夸大隔离**）。

## 数据都在哪

- 全部用户数据在本机 `~/.lynn/`（环境变量 `LYNN_HOME` 可重定向）：设置、会话、任务卷宗、知识库、技能、插件、审计日志。
- 卸载不清数据（`deleteAppDataOnUninstall: false`）；删目录即彻底删除。

## 凭据

- API Key（模型 / 视觉模型 / 消息平台 Secret）用操作系统级 **safeStorage** 加密后落 `settings.json` / `messaging.json`；加密不可用时降级明文并打标（文件仍在本机）。
- 明文 Key 永不下发到界面层；插件永不直读凭据（L1 凭据按需代理下发）。

## 遥测与外联

- **应用自身无遥测、无崩溃上报、无用量统计上传。**
- Pi 运行时的遥测与版本检查在启动时以环境变量禁用（`PI_TELEMETRY=0` 等），并有自动化测试锁定。
- 出网只发生在：① 你配置的**模型端点**（对话 / 成员执行直连该端点）；② 你显式配置的 MCP server；③ 成员使用浏览器工具访问的网页（可见、可接管）；④ 你配置的消息平台官方 API。
- 自动更新默认关闭自动下载，检查到新版本后由你确认（feed 地址可自定义）。

## 隔离的真实边界（不夸大）

- 成员的文件读写被钉死在本次任务的工作区 / 草稿区；命令执行有危险命令拦截（18 条规则）、超时、输出截断与审计账本（`~/.lynn/audit.jsonl`）。
- **以上是纵深防御，不是操作系统级沙箱**：成员命令跑在你的用户权限下。需要更强隔离时请把 lynn 跑在容器 / 受限账户里（上游 Pi 生态同样建议容器化隔离）。
- L1 插件与内核同进程同权限（高信任档）：第三方 L1 默认停用、须逐项确认；禁项扫描命中即拒；崩溃由安全模式与回滚兜底。
- U 档界面组件跑在 iframe 沙箱：禁网络、禁 Node。
- 浏览器工具驱动你本机 Edge（可见窗口，可随时接管）；登录 / 支付 / 验证码类页面代码层强制拦截，需要你确认才继续。
- 消息平台只走官方开放平台 API + 你自建应用；**收消息（长连接）当前未实现**，只有配置与发送。

## 审计

`~/.lynn/audit.jsonl` 只追加：命令拦截 / 出站 / 执行 / 工坊启用人（含「风铃自启用 L0」这类动作）都有留痕，独立于被审计者可查。
