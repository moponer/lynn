# 清洗核算说明（clean-log）

## 0. 摘要

- 原始数据行（不含表头）：119 行；重复订单号删除 2 行；保留 117 行，全部写入 `orders-clean.csv`。
- 七类脏点全部显式处理；无 ESCALATE 项。

## 1. 逐类脏点与处理口径

1. **日期格式混杂（3 种写法）**
   - `YYYY-MM-DD`：47 行，原样保留
   - `YYYY/M/D`（如 2026/7/08）：47 行，补零统一为 YYYY-MM-DD
   - `DD.MM.YYYY`（如 01.09.2026）：23 行，按「日.月.年」解析，01.09.2026 → 2026-09-01。口径依据：此类写法的第二段在全部行中均为 09，按「日.月.年」解析才能落在本数据集 Q3（7-9 月）范围内；若按「月.日.年」会得到 1 月，与全表矛盾，故排除。
   - 无法解析的日期：0 行

2. **单价/金额带 ￥ 与千分位**：单价列含 ￥ 16 处、金额列含 ￥ 10 处（共 26 处），处理 = 去掉 ￥ 保留数字。含千分位逗号的数值：单价 0 处、金额 0 处（经全量检查本表未出现千分位，如实记 0 处；处理规则备用 = 去逗号）。

3. **金额缺失**：21 行，处理 = 补算金额 = 单价 × 数量（其中退货单 2 行补为负值）。依据：所有已填金额行均满足「金额 = 单价 × 数量」（见第 7 条校验零不一致），故缺失值可用同一关系可靠还原。

4. **数量为负（退货）**：13 行，处理 = 保留负数量与负金额，月报计入「退货单数」，其金额以负数计入 GMV。

5. **城市空值**：19 行，处理 = 保留空字符串不填充，仅计数；本报告无城市维度汇总，故不影响任何数字。

6. **重复订单号**：2 行 —— SO-20261004（原始第 119 行，与第 5 行内容完全一致，保留首条）；SO-20261005（原始第 120 行，与第 6 行内容完全一致，保留首条）。处理 = 保留首次出现行，删除后续重复行。

7. **金额一致性校验**（已填金额行 vs 单价×数量）：不一致 0 行（全部一致）。

字段结构异常（列数≠8）行：0 行。

## 2. 行数对账式

- 原始数据行 119 = 去重删除 2 + 保留 117
- 保留 117 = 补算金额 21 行 + 原有金额 96 行（0 行因缺失被删除）
- `orders-clean.csv` 数据行 = 117（与保留行数一致，0 行丢失）

## 3. 月报数字复算口径（可逐项复算）

每组小计 = 单价 × 数量 × 笔数；月 GMV = 各组小计之和（退货组数量为负、小计为负，已含在内）。
